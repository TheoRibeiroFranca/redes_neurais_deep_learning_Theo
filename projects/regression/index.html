    Dataset, decisões e status: página do projeto.

    Rede neural treinada no mesmo dataset, com a mesma tarefa e o mesmo split do EDA: prever o retorno logarítmico do minuto seguinte do BTC/USD (ret_futuro = log(Close[t+1] / Close[t])) a partir de ret_1, amplitude, direcao e log1p(Volume). A pergunta que guia a entrega: a rede aprende algo que modelos simples não aprendem? E até que ponto dá para confiar no número que ela reporta?

    0. Ponto de partida

    O pipeline do EDA é importado de ../eda/code/exercise4.py (build_features, split, make_preprocess), sem cópia, e ajustado só no treino.

    Correções do EDA

    Não recebemos comentário da correção do EDA. Revisando o relatório, encontramos estes pontos, que corrigimos aqui sem alterar a pasta do EDA:

    1. A tabela da §1 do EDA diz que a tarefa é prever o Close, mas o alvo usado é ret_futuro. Nesta entrega o alvo é sempre ret_futuro.
    2. A análise do alvo (1C) foi feita sobre o Close. Aqui ela é refeita sobre ret_futuro, só no treino.
    3. As estatísticas e o Spearman da §1D foram calculados no dataset inteiro, antes do split. Aqui toda estatística nova usa só o treino.
    4. O baseline "prever zero" do EDA foi medido no teste. Aqui os baselines são avaliados na validação, e o teste só aparece na seção 5.

    Métrica principal e critério de sucesso (definidos antes de treinar)

    • Métrica principal: RMSE, na escala original do log-retorno. MAE e \(R^2\) aparecem ao lado. Escolhemos o RMSE porque a mediana do alvo no treino é 0 e boa parte dos minutos não tem variação: o MAE favorece prever zero, enquanto o RMSE mede o erro em torno da média condicional, que é o que uma rede treinada com perda quadrática ou Huber tenta estimar (Aula 8.2).
    • Critério de sucesso: a rede atinge o critério se as duas condições valerem:
      1. o RMSE de teste da rede (média de 3 seeds) é pelo menos 0,5% menor que o RMSE de teste do melhor baseline, escolhido na validação;
      2. essa diferença é maior que 2 desvios-padrão do RMSE entre as seeds.
    • O exemplo do enunciado (15% de melhora) não é realista para o retorno de um minuto: no EDA a correlação mais forte entre uma feature e o alvo foi de −0,11 (Spearman). Um ganho de 0,5% no RMSE equivale a explicar cerca de 1 ponto percentual a mais da variância do alvo (\(1 - 0{,}995^2 \approx 0{,}01\)).

    # MLP da entrega 2: Linear -> ReLU -> (Dropout) ... -> Linear(1), saída linear para regressão.
# Aula 5 (MLP): camadas densas com ReLU; sem ativação na saída, porque o alvo é um número real.
# Aula 9 (Deep Networks): init He (kaiming_normal_, sigma^2 = 2/n, fan_in) para ReLU e vieses em zero.
#   O padrão do nn.Linear (kaiming_uniform_(a=sqrt(5))) tem variância 1/(3n), um sexto da He.
# Aula 7 (Regularização): dropout depois da ReLU nas camadas ocultas, nunca na saída.
import torch
import torch.nn as nn


class MLP(nn.Module):
    def __init__(self, n_in: int, hidden: list[int], dropout: float = 0.0):
        super().__init__()
        layers = []
        prev = n_in
        for h in hidden:
            layers += [nn.Linear(prev, h), nn.ReLU()]
            if dropout > 0:
                layers.append(nn.Dropout(dropout))
            prev = h
        layers.append(nn.Linear(prev, 1))  # saída linear, 1 unidade
        self.net = nn.Sequential(*layers)
        self.reset_parameters()

    def reset_parameters(self):
        # Aula 9: He com fan_in em todas as camadas lineares, vieses em zero
        for m in self.modules():
            if isinstance(m, nn.Linear):
                nn.init.kaiming_normal_(m.weight, mode="fan_in", nonlinearity="relu")
                nn.init.zeros_(m.bias)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        return self.net(x).squeeze(-1)  # (n,)


def n_params(model: nn.Module) -> int:
    return sum(p.numel() for p in model.parameters() if p.requires_grad)

    Escolha Por quê
    Otimizador AdamW (β₁ = 0,9, β₂ = 0,999) A Aula 6 indica Adam com lr 1e-3 como padrão para MLP em dados tabulares. O AdamW separa o weight decay da perda; o decay entra só nos pesos, sem os vieses (Aulas 6 e 7)
    Learning rate 1e-3 (3e-4 e 3e-3 testados em 4B) Padrão da Aula 6. Na busca, 1e-3 foi melhor que os dois vizinhos em escala log
    Batch size 4 096 Com milhões de linhas, um batch maior reduz o ruído do gradiente (σ/√B, Aula 6) e deixa a época em poucos segundos na CPU
    Épocas (máx.) / paciência 30 / 5 Early stopping pela perda de validação, restaurando o melhor state_dict, como no esqueleto do enunciado (Aula 7)

    A perda de treino e a de validação são medidas no conjunto inteiro ao fim de cada época, em modo eval (Handout de Otimização §5.1).

    Leitura da Figura 2.

    • A melhor época é a 1. A perda de validação sobe de 0,2344 na época 1 para 0,2377 na época 6, e o early stopping para na 6 e restaura os pesos da época 1. A perda de treino cai de 0,9999 para 0,9924. Pela tabela da Aula 7, validação parada ou subindo enquanto o treino cai é overfitting: a rede aprende algo de 2018–2022 que não vale em 2023.
    • A validação fica abaixo do treino, e isso não é vazamento. A tabela da Aula 7 cita dois motivos para a validação ficar melhor que o treino: dropout ligado na avaliação ou vazamento. Aqui não é nenhum dos dois:
    • a perda de treino também é medida em modo eval;
    • a perda está em unidades de \(\sigma_{tr}\), e 2023 tem variância bem menor que 2018–2022 (desvio de 5,80e-4 contra 1,98e-3 no treino completo). Prever a média dá a mesma diferença.
    • A perda de treino perto de 1 quer dizer que a rede explica menos de 1% da variância do próprio treino.

    O run levou 206 s com 8 threads. As 16 configurações da busca levaram de 51 s a 652 s cada.

    Código do treino: train.py 
    # Treino de uma configuração da MLP (passos 2 e 3) com early stopping pela validação.
# Loop: esqueleto do enunciado (early stopping, paciência, restaurar o melhor state_dict).
# Aula 6 (Otimização): AdamW, lr 1e-3 como ponto de partida; weight decay só nos pesos,
#   vieses sem decay ("Do not decay every parameter"); mini-batch embaralhado a cada época.
# Aula 7 (Regularização): early stopping em três partes (validação por época, paciência,
#   restaurar o melhor checkpoint); model.eval() na avaliação por causa do dropout.
# Aula 8.2 (Métricas de regressão): perda Huber (quadrática até delta, linear depois) ou MSE;
#   RMSE, MAE e R² como métricas.
# Aula 2 (Scaling the target): a perda usa y / y_std (y_std do treino); as métricas voltam
#   à escala original antes de medir.
# Handout de Otimização: §5.1 perda no conjunto inteiro por época (treino e validação, em
#   lotes, sem gradiente); tensores criados uma vez, sem DataLoader; semente 42.
# O teste não é lido aqui: X_te/y_te são descartados logo depois de carregar.
import argparse
import json
import math
import os
import time
from pathlib import Path

import numpy as np
import torch
import torch.nn as nn
from sklearn.metrics import mean_absolute_error, r2_score, root_mean_squared_error

from features import load_arrays
from model import MLP, n_params

CODE = Path(__file__).resolve().parent
ROOT = CODE.parents[3]
RES = CODE.parent / "results"
RUNS_DIR = RES / "runs"
MODELS_DIR = RES / "models"
PREDS_DIR = ROOT / "data" / "cache" / "preds"

EVAL_BS = 65_536

DEFAULTS = {
    "name": None,
    "feature_set": "F65",
    "window": "full",
    "hidden": [128, 64],
    "dropout": 0.0,
    "weight_decay": 0.0,
    "lr": 1e-3,
    "batch": 4096,
    "max_epochs": 30,
    "patience": 5,
    "loss": "huber",
    "huber_delta": 1.0,
    "seed": 42,
    "threads": int(os.environ.get("NUM_THREADS", 3)),
    "max_rows": None,
}


def make_loss(cfg, reduction="mean"):
    if cfg["loss"] == "huber":
        return nn.HuberLoss(delta=cfg["huber_delta"], reduction=reduction)
    if cfg["loss"] == "mse":
        return nn.MSELoss(reduction=reduction)
    raise ValueError(f"loss desconhecida: {cfg['loss']}")


def make_optimizer(model, cfg):
    # Aula 6: dois grupos, pesos (matrizes) com decay e vieses sem decay
    decay = [p for n, p in model.named_parameters() if p.ndim >= 2]
    no_decay = [p for n, p in model.named_parameters() if p.ndim < 2]
    return torch.optim.AdamW(
        [{"params": decay, "weight_decay": cfg["weight_decay"]},
         {"params": no_decay, "weight_decay": 0.0}],
        lr=cfg["lr"],
    )


@torch.no_grad()
def evaluate(model, X, y_s, loss_sum, bs=EVAL_BS):
    """Perda média no conjunto inteiro (y padronizado) e previsões na escala padronizada."""
    model.eval()
    total = 0.0
    preds = np.empty(len(X), dtype=np.float32)
    for i in range(0, len(X), bs):
        out = model(X[i:i + bs])
        total += loss_sum(out, y_s[i:i + bs]).item()
        preds[i:i + bs] = out.numpy()
    return total / len(X), preds


def metrics(y, yhat):
    y = y.astype(np.float64)
    yhat = yhat.astype(np.float64)
    return {
        "rmse": float(root_mean_squared_error(y, yhat)),
        "mae": float(mean_absolute_error(y, yhat)),
        "r2": float(r2_score(y, yhat)),
    }


def train_run(cfg: dict) -> dict:
    cfg = {**DEFAULTS, **cfg}
    if not cfg["name"]:
        raise ValueError("cfg['name'] é obrigatório")
    cfg["hidden"] = [int(h) for h in cfg["hidden"]]
    name = cfg["name"]
    t_start = time.time()

    torch.set_num_threads(int(cfg["threads"]))
    torch.manual_seed(cfg["seed"])
    rng = np.random.default_rng(cfg["seed"])

    d = load_arrays(cfg["feature_set"], cfg["window"])
    for k in ("X_te", "y_te"):  # regra 4 do contrato: teste fora do desenvolvimento
        d.pop(k, None)
    y_std = float(d["y_std"])

    X_tr_np, y_tr_np = d["X_tr"], d["y_tr"]
    if cfg["max_rows"] is not None and cfg["max_rows"] < len(X_tr_np):
        # subamostra só para smoke test; y_std e escala continuam os do tr completo
        idx = np.sort(rng.choice(len(X_tr_np), size=int(cfg["max_rows"]), replace=False))
        X_tr_np, y_tr_np = X_tr_np[idx], y_tr_np[idx]

    # tensores criados uma vez (from_numpy não copia); o alvo da perda é y / y_std
    X_tr = torch.from_numpy(np.ascontiguousarray(X_tr_np, dtype=np.float32))
    y_tr_s = torch.from_numpy((y_tr_np / y_std).astype(np.float32))
    X_val = torch.from_numpy(np.ascontiguousarray(d["X_val"], dtype=np.float32))
    y_val = d["y_val"].astype(np.float32)
    y_val_s = torch.from_numpy(y_val / y_std)
    n = len(X_tr)

    torch.manual_seed(cfg["seed"])  # mesma inicialização para a mesma semente
    model = MLP(X_tr.shape[1], cfg["hidden"], cfg["dropout"])
    opt = make_optimizer(model, cfg)
    loss_fn = make_loss(cfg)
    loss_sum = make_loss(cfg, reduction="sum")
    g = torch.Generator().manual_seed(cfg["seed"])

    for p in (RUNS_DIR, MODELS_DIR, PREDS_DIR):
        p.mkdir(parents=True, exist_ok=True)
    best_path = MODELS_DIR / f"{name}.pt"

    history = []
    best, wait, best_epoch, stop_epoch = float("inf"), 0, None, 0
    bs = int(cfg["batch"])
    for epoch in range(1, cfg["max_epochs"] + 1):
        t0 = time.time()
        model.train()
        perm = torch.randperm(n, generator=g)  # embaralha a cada época
        for i in range(0, n, bs):
            idx = perm[i:i + bs]
            opt.zero_grad(set_to_none=True)
            loss = loss_fn(model(X_tr[idx]), y_tr_s[idx])
            loss.backward()
            opt.step()

        train_loss, _ = evaluate(model, X_tr, y_tr_s, loss_sum)  # treino inteiro, modo eval
        val_loss, pv = evaluate(model, X_val, y_val_s, loss_sum)
        m = metrics(y_val, pv * y_std)
        history.append({"epoch": epoch, "train_loss": train_loss, "val_loss": val_loss,
                        "val_rmse": m["rmse"], "val_mae": m["mae"],
                        "seconds": time.time() - t0})
        stop_epoch = epoch
        print(f"[{name}] época {epoch:2d}  train {train_loss:.6f}  val {val_loss:.6f}  "
              f"val_rmse {m['rmse']:.4e}  {history[-1]['seconds']:.1f}s", flush=True)

        if not math.isfinite(train_loss) or not math.isfinite(val_loss):
            print(f"[{name}] divergiu na época {epoch}", flush=True)
            break
        if val_loss < best:
            best, wait, best_epoch = val_loss, 0, epoch
            torch.save(model.state_dict(), best_path)  # guarda os melhores pesos
        else:
            wait += 1
            if wait == cfg["patience"]:
                break

    if best_epoch is None:
        raise RuntimeError(f"[{name}] nenhuma época com perda de validação finita")

    result = {

    with open(RUNS_DIR / f"{name}.json", "w", encoding="utf-8") as f:

    7. Conclusão

    A rede não valeu a pena para esta tarefa. No teste, ela empata com prever a média: RMSE de 6,8227e-4 ± 1,3e-7 contra 6,8208e-4. Ela não atinge o critério de 0,5% fixado antes do treino, e o Ridge também não bate a média. O resultado mais útil da entrega é o motivo:

    • A relação que o EDA mediu é do mercado antigo. A correlação de −0,120 entre ret_1 e o alvo em 2012–2022 cai para −0,003 em 2023. Treinar só em 2018–2022 melhorou todos os modelos, mas nenhum passou da média.
    • Arquitetura, regularização e otimizador mexem pouco no erro, porque a limitação está na informação que as entradas carregam sobre o próximo minuto (Aula 1: num problema tabular de poucas features, empatar com o simples é um resultado esperado).

    Limitações.

    • Usamos uma única exchange (Bitstamp).
    • O horizonte é de 1 minuto.
    • Nos minutos sem negócio, o preço é repetido, não negociado.
    • A versão do CSV é diferente da do EDA (seção 0).
    • A validação e o teste são bem mais calmos que o treino, e a busca usou só um corte de validação (2023).
    • A importância por permutação não é método de aula, e famílias correlacionadas (ret_1 e direcao) dividem a importância entre si.

    Quem seria afetado por um erro. O afetado seria quem usasse a previsão para operar ou para medir risco de curto prazo. O modelo não deve ser usado para nenhum dos dois. Como sinal de direção, ele acerta 49,89%, que é o nível de uma moeda.

    Com mais tempo, faríamos:

    1. Horizonte maior (1 hora ou 1 dia), em que o ruído de microestrutura pesa menos.
    2. Prever a volatilidade (|alvo|) em vez do retorno. As features mostraram que dizem "quanto" o preço mexe, e o erro por subgrupo confirma isso.
    3. Validação com mais de um corte no tempo (TimeSeriesSplit, Aula 2) e treino em janela móvel.
    4. Modelos de sequência (RNN ou LSTM, Aula 11), se a tarefa mudar para um horizonte em que a ordem dos minutos carregue informação.

def split_positions(feats: pd.DataFrame, window: str) -> dict:
    """Posições (slices) de tr, val e te em feats, usando split() do EDA e split_train_val() do data.py."""
    X_train, y_train, X_test, _ = split(feats)
    x_tr, _, x_val, _ = split_train_val(X_train, y_train)
    if window == "2018":
        x_tr = x_tr[x_tr.index >= WIN_2018]
    elif window != "full":
        raise ValueError(window)
    out = {}
    for part, idx in (("tr", x_tr.index), ("val", x_val.index), ("te", X_test.index)):
        a = feats.index.get_loc(idx[0])
        b = feats.index.get_loc(idx[-1]) + 1
        assert b - a == len(idx), "partes do split deveriam ser contíguas"
        out[part] = slice(a, b)
    return out


def lag_block(base: np.ndarray, rv: np.ndarray, sl: slice, offset: int) -> np.ndarray:
    """Matriz F65 crua das linhas sl de feats. base é (n, 4) com as linhas de feats precedidas
    por `offset` linhas de passado (offset >= N_LAGS), para os lags das primeiras linhas."""
    win = sliding_window_view(base, N_LAGS + 1, axis=0)  # (n-15, 4, 16): win[i, f, k] = base[i+k, f]
    n = sl.stop - sl.start
    X = np.empty((n, 4 * (N_LAGS + 1) + 1), dtype=np.float32)
    for a in range(0, n, CHUNK):
        b = min(a + CHUNK, n)
        # linha t de feats está em base[t + offset]; janela que termina nela começa em t+offset-15
        i0 = sl.start + a + offset - N_LAGS
        blk = win[i0:i0 + (b - a), :, ::-1]  # inverte: posição j = lag j
        X[a:b, :-1] = blk.reshape(b - a, -1)
    X[:, -1] = rv[sl]
    return X


def f65_names() -> list:
    return [f"{f}_lag{j}" for f in BASES for j in range(N_LAGS + 1)] + ["rv_60"]


def families_of(names: list) -> dict:
    fam = {}
    for i, name in enumerate(names):
        key = "rv_60" if name == "rv_60" else FAMILY_OF[name.split("_lag")[0]]
        fam.setdefault(key, []).append(i)
    return fam


def scale_inplace(X_tr, others):
    """StandardScaler: fit só em X_tr (em blocos, partial_fit), transform em todos, no lugar."""
    scaler = StandardScaler()
    for a in range(0, len(X_tr), CHUNK):
        scaler.partial_fit(X_tr[a:a + CHUNK])
    for X in [X_tr, *others]:
        for a in range(0, len(X), CHUNK):
            X[a:a + CHUNK] = scaler.transform(X[a:a + CHUNK])
    return scaler.mean_, scaler.scale_

        preco = pre.named_transformers_["preco"]
        vol = pre.named_transformers_["volume"].named_steps["scale"]
        x_mean = np.r_[preco.mean_, vol.mean_]
        x_scale = np.r_[preco.scale_, vol.scale_]
        names = list(BASES)
    elif feature_set == "F65":
        # base = as 15 linhas de passado (descartadas da 1ª parte) + as linhas de feats

        rv = feats["rv_60"].to_numpy(np.float32)
        for part in ("tr", "val", "te"):
            out[f"X_{part}"] = lag_block(base, rv, pos[part], offset=N_LAGS)
        del base
        x_mean, x_scale = scale_inplace(out["X_tr"], [out["X_val"], out["X_te"]])
        names = f65_names()
    else:
        raise ValueError(feature_set)

    for part in ("tr", "val", "te"):
        rows = feats.iloc[pos[part]]

def load_feats():
    """Lê o CSV (data.py), aplica build_features do EDA e acrescenta log1p(Volume) e rv_60.

    build_features já tira a 1ª linha (ret_1) e a última (alvo). rv_60 = rolling(60) sem
    center: usa ret_1 de t-59 até t (Aula 2, Leakage §3). Descarta as linhas iniciais em que
    rv_60 ou algum lag não existe; devolve também as 15 linhas anteriores (para os lags).
    """
    full = build_features(load_raw())
    full["log1p_Volume"] = np.log1p(full["Volume"])
    full["rv_60"] = full["ret_1"].rolling(RV_WINDOW).std()  # ddof=1, só para trás
    n_drop = max(RV_WINDOW - 1, N_LAGS)
    assert full["rv_60"].iloc[n_drop:].notna().all()
    feats = full.iloc[n_drop:].copy()
    past = full[BASES].iloc[n_drop - N_LAGS:n_drop].to_numpy(np.float32)
    return feats, past

def _load(path: Path) -> dict:
    with np.load(path, allow_pickle=False) as z:

def metrics(y, yhat):
    return {
        "rmse": float(root_mean_squared_error(y, yhat)),
        "mae": float(mean_absolute_error(y, yhat)),

def ridge_fit_blocks(X, y, alpha):
    """Ridge com intercepto não penalizado (mesma definição do sklearn), em dois passes por blocos.

    Passe 1: médias de X e y. Passe 2: X'X e X'y centrados. Depois w = (X'X + alpha I)^-1 X'y.
    """
    n, p = X.shape
    mu_x = np.zeros(p)
    mu_y = 0.0
    for i in range(0, n, BLOCK):
        mu_x += X[i : i + BLOCK].astype(np.float64).sum(axis=0)
        mu_y += float(y[i : i + BLOCK].astype(np.float64).sum())
    mu_x /= n
    mu_y /= n

    gram = np.zeros((p, p))
    xty = np.zeros(p)
    for i in range(0, n, BLOCK):
        xb = X[i : i + BLOCK].astype(np.float64) - mu_x
        yb = y[i : i + BLOCK].astype(np.float64) - mu_y
        gram += xb.T @ xb
        xty += xb.T @ yb

    coef = np.linalg.solve(gram + alpha * np.eye(p), xty)
    intercept = mu_y - mu_x @ coef
    return coef, intercept


def ridge_object(alpha, coef, intercept, n_features):
    """Objeto sklearn Ridge com os atributos ajustados preenchidos (para o pkl e o predict padrão)."""
    model = Ridge(alpha=alpha)
    model.coef_ = coef
    model.intercept_ = intercept
    model.n_features_in_ = n_features
    return model

def score(rec):
    """val_rmse para comparar. NaN (run divergido) perde sempre."""
    v = rec["val"]["rmse"]
    return math.inf if math.isnan(v) else v


def best_name(names, done):
    """Menor val_rmse entre os nomes. Empate: o primeiro da lista. Sem run válida, para."""
    winner = min(names, key=lambda n: score(done[n][1]))
    if score(done[winner][1]) == math.inf:
        raise RuntimeError(f"nenhuma run válida entre {names}; veja as falhas acima")
    return winner


def failed_record(cfg, err):
    """Registro só em memória para um run que levantou erro. Não grava json: na próxima
    execução o run é tentado de novo (ex.: divergência logo na 1ª época, ou cache faltando)."""
    nan = float("nan")
    return {"cfg": cfg, "n_params": None, "best_epoch": None,
            "val": {"rmse": nan, "mae": nan, "r2": nan}, "failed": repr(err)}


def run_stage(cfgs, train_fn, workers, runs_dir):
    """Roda as cfgs em paralelo (ProcessPoolExecutor). Quem já tem json é lido e não refeito."""
    runs_dir.mkdir(parents=True, exist_ok=True)
    out, todo = {}, []
    for cfg in cfgs:
        path = runs_dir / f"{cfg['name']}.json"
        if path.exists():
            out[cfg["name"]] = json.loads(path.read_text(encoding="utf-8"))
            print(f"[pula] {cfg['name']}: json existe", flush=True)
        else:
            todo.append(cfg)
    if todo:
        cfg_of = {c["name"]: c for c in todo}
        with ProcessPoolExecutor(max_workers=workers) as ex:
            futs = {ex.submit(train_fn, cfg): cfg["name"] for cfg in todo}
            for fut in as_completed(futs):
                name = futs[fut]
                try:
                    out[name] = fut.result()
                    print(f"[ok] {name}: val_rmse={out[name]['val']['rmse']:.6g}", flush=True)
                except Exception as err:  # falha de um run não derruba a etapa
                    out[name] = failed_record(cfg_of[name], err)
                    print(f"[falhou] {name}: {err!r} (sem json; rode de novo para tentar)", flush=True)
    return out

def search(train_fn, smoke, workers, threads):
    tag = "_smoke" if smoke else ""
    pre = "smoke_" if smoke else ""
    base = {**BASE, "threads": threads, **(SMOKE_OVERRIDES if smoke else {})}
    n4a = [pre + n for n, _, _ in REG_4A]
    n4b = [pre + f"g{i:02d}" for i in range(1, 13)]
    done = {}  # nome -> (cfg, record)
    RES.mkdir(parents=True, exist_ok=True)

    def stage(cfgs):
        recs = run_stage(cfgs, train_fn, workers, RUNS)
        for c in cfgs:
            done[c["name"]] = (c, recs[c["name"]])

    def save_4a():
        write_grid(RES / f"grid_4a{tag}.csv", [row(*done[n]) for n in n4a if n in done])

    def save_4b():
        write_grid(RES / f"grid_4b{tag}.csv", [row(*done[n]) for n in n4b if n in done])

    def derive(src_names, new_name, **changes):
        """Cópia da melhor (até aí) entre src_names, com nome novo e mudanças."""
        src = done[best_name(src_names, done)][0]
        return {**src, "name": pre + new_name, **changes}

    # 4A: regularização, base F65 full [128, 64].
    cfgs = [{**base, "name": pre + n, "weight_decay": wd, "dropout": dp} for n, wd, dp in REG_4A]
    stage(cfgs)
    save_4a()
    reg = done[best_name(n4a, done)][0]
    print(f"4A: melhor regularização = {reg['name']} (weight_decay={reg['weight_decay']}, dropout={reg['dropout']})", flush=True)

    # g01-g08: F4/F65 x full/2018 x [64, 32]/[256, 128], lr 1e-3, Huber, regularização de 4A.
    cfgs = []
    for fs in ("F4", "F65"):
        for win in ("full", "2018"):
            for hid in ([64, 32], [256, 128]):
                cfgs.append({**base, "name": pre + f"g{len(cfgs) + 1:02d}", "feature_set": fs,
                             "window": win, "hidden": hid, "weight_decay": reg["weight_decay"],
                             "dropout": reg["dropout"], "lr": 1e-3, "loss": "huber"})
    stage(cfgs)
    save_4b()

    # g09, g10: melhor de g01-g08 com lr 3e-4 e 3e-3.
    cfgs = [derive(n4b[:8], "g09", lr=3e-4), derive(n4b[:8], "g10", lr=3e-3)]
    stage(cfgs)
    save_4b()

    # g11: melhor de g01-g10 com [256, 128, 64].
    stage([derive(n4b[:10], "g11", hidden=[256, 128, 64])])
    save_4b()

    # g12: melhor de g01-g11 com loss mse.
    stage([derive(n4b[:11], "g12", loss="mse")])
    save_4b()

    all_names = n4a + n4b
    winner = best_name(all_names, done)
    print(f"Configurações tentadas: {len(n4a)} em 4A + {len(n4b)} em 4B = {len(all_names)}", flush=True)
    print(f"Melhor por val_rmse: {winner} (val_rmse={done[winner][1]['val']['rmse']:.6g})", flush=True)
    print(f"Saídas: {RES / ('grid_4a' + tag + '.csv')} e {RES / ('grid_4b' + tag + '.csv')}", flush=True)

def dados_do_split(arrays: dict, parte: str) -> dict:
    return {
        "X": arrays[f"X_{parte}"],
        "y": arrays[f"y_{parte}"],
        "ret1": arrays[f"ret1_{parte}"],
        "ts": arrays[f"ts_{parte}"],
        "vol0": arrays[f"vol0_{parte}"],
        "rv60": arrays[f"rv60_{parte}"],
    }


def preparar(fs: str, window: str, parte: str) -> dict:
    """Carrega uma combinação F4/F65 x full/2018 e guarda só o que o script usa."""
    arr = load_arrays(fs, window)
    pacote = {
        "dados": dados_do_split(arr, parte),
        "media_tr": float(arr["y_tr"].mean()),
        "mediana_tr": float(np.median(arr["y_tr"])),
        "y_std": float(arr["y_std"]),
    }
    del arr
    return pacote


def carregar_rede(cfg: dict, n_in: int, nome: str) -> MLP:
    rede = MLP(n_in, list(cfg["hidden"]), dropout=float(cfg["dropout"]))
    estado = torch.load(RES / "models" / f"{nome}.pt", map_location="cpu", weights_only=True)
    rede.load_state_dict(estado)
    rede.eval()
    return rede


@torch.no_grad()
def prever_rede(rede: MLP, X: np.ndarray, y_std: float) -> np.ndarray:
    saida = np.empty(len(X), dtype=np.float64)
    for i in range(0, len(X), BATCH):
        xb = torch.from_numpy(np.ascontiguousarray(X[i:i + BATCH], dtype=np.float32))
        saida[i:i + BATCH] = rede(xb).squeeze(-1).numpy()
    return saida * y_std  # volta à escala original


def prever_baseline(modelo: str, pacote: dict, fs: str, window: str) -> np.ndarray:
    n = len(pacote["dados"]["y"])
    if modelo == "dummy_mean":
        return np.full(n, pacote["media_tr"])
    if modelo == "dummy_median":
        return np.full(n, pacote["mediana_tr"])
    if modelo == "zero":
        return np.zeros(n)
    if modelo == "persistencia":  # previsão de ret_1 do minuto t (último valor observado)
        return pacote["dados"]["ret1"].astype(np.float64)
    if modelo == "ridge":
        with open(RES / "models" / f"ridge_{fs}_{window}.pkl", "rb") as f:
            ridge = pickle.load(f)
        return ridge.predict(pacote["dados"]["X"])
    raise ValueError(f"baseline desconhecido em baselines_best.json: {modelo}")


def metricas(y: np.ndarray, yhat: np.ndarray) -> dict:
    return {
        "rmse": float(root_mean_squared_error(y, yhat)),
        "mae": float(mean_absolute_error(y, yhat)),
        "r2": float(r2_score(y, yhat)),
    }

    # Rede: três sementes, previsões na escala original.
    p_net = preparar(fs, window, parte)
    d = p_net["dados"]
    n_in = d["X"].shape[1]
    previsoes = []
    for s in SEEDS:
        rede = carregar_rede(cfg, n_in, f"final_s{s}")
        previsoes.append(prever_rede(rede, d["X"], p_net["y_std"]))
        print(f"semente {s}: previsto")
    yhat_seeds = np.column_stack(previsoes)
    yhat_media = yhat_seeds.mean(axis=1)

    por_semente = [{"seed": s, **metricas(d["y"], yhat_seeds[:, i])} for i, s in enumerate(SEEDS)]
    rede_media = {k: float(np.mean([m[k] for m in por_semente])) for k in ("rmse", "mae", "r2")}
    rede_dp = {k: float(np.std([m[k] for m in por_semente], ddof=1)) for k in ("rmse", "mae", "r2")}
    rede_ensemble = metricas(d["y"], yhat_media)

    # Baselines no mesmo split. O melhor vem do json escolhido na validação.
    base_pred = {
        "media_treino": prever_baseline("dummy_mean", p_net, fs, window),
        "zero": prever_baseline("zero", p_net, fs, window),
        "persistencia": prever_baseline("persistencia", p_net, fs, window),
        "ridge_mesmo_conjunto": prever_baseline("ridge", p_net, fs, window),
    }

    rmse_melhor = melhor_metricas["rmse"]

    diferenca = rmse_melhor - rmse_rede
    limite_cond2 = K_DESVIOS * rede_dp["rmse"]
    cond1 = rmse_rede <= limite_cond1
    cond2 = diferenca > limite_cond2
    aprovado = bool(cond1 and cond2)

    (CACHE / "preds").mkdir(parents=True, exist_ok=True)

    linhas = [("rede_semente_%d" % m["seed"], m["rmse"], m["mae"], m["r2"]) for m in por_semente]

    linhas.append(("rede_desvio_3_sementes", rede_dp["rmse"], rede_dp["mae"], rede_dp["r2"]))
    linhas.append(("rede_yhat_media_sementes", rede_ensemble["rmse"], rede_ensemble["mae"], rede_ensemble["r2"]))
    for nome, m in base_metricas.items():
        linhas.append((f"baseline_{nome}", m["rmse"], m["mae"], m["r2"]))
    linhas.append((f"melhor_baseline_validacao_{melhor['model']}", melhor_metricas["rmse"],
                   melhor_metricas["mae"], melhor_metricas["r2"]))

    with open(RES / f"test_table{sufixo}.csv", "w", newline="", encoding="utf-8") as f:
        w = csv.writer(f)
        w.writerow(["modelo", "rmse", "mae", "r2"])
        for nome, rmse, mae, r2 in linhas:
            w.writerow([nome, f"{rmse:.8f}", f"{mae:.8f}", f"{r2:.8f}"])

    np.savez(
        CACHE / "preds" / f"test_preds{sufixo}.npz",
        y=d["y"], yhat=yhat_media, yhat_seeds=yhat_seeds,
        ts=d["ts"], vol0=d["vol0"], rv60=d["rv60"], ret1=d["ret1"],
        split=nome_split,
    )

    resultado = {
        "timestamp": datetime.now().isoformat(timespec="seconds"),
        "modo": "dryrun_val" if dry else "teste",
        "split": nome_split,
        "n_linhas": int(len(d["y"])),
        "chosen": cfg,
        "por_semente": por_semente,
        "rede_media_3_sementes": rede_media,
        "rede_desvio_3_sementes": rede_dp,
        "rede_yhat_media_sementes": rede_ensemble,
        "baselines": base_metricas,
        "melhor_baseline": {
            "modelo": melhor["model"],
            "feature_set": base_fs,
            "window": base_window,
            "rmse_no_json_validacao": melhor.get("rmse"),
            **melhor_metricas,
        },
        "criterio": {
            "regra": "rmse_rede_media <= 0,995 x rmse_melhor_baseline E diferenca > 2 x dp_rmse_sementes",
            "rmse_rede_media": rmse_rede,
            "rmse_melhor_baseline": rmse_melhor,
            "cond1_limite": limite_cond1,
            "cond1_ok": bool(cond1),
            "diferenca": diferenca,
            "cond2_limite": limite_cond2,
            "cond2_ok": bool(cond2),
        },
        "aprovado": aprovado,
    }
    (RES / f"test_metrics{sufixo}.json").write_text(
        json.dumps(resultado, indent=2, ensure_ascii=False), encoding="utf-8"

def importancia(nome: str, prever, X: np.ndarray, y: np.ndarray, familias: dict) -> list:
    base = root_mean_squared_error(y, prever(X))
    linhas = []
    for familia, cols in familias.items():
        cols = np.asarray(cols)
        rng = np.random.default_rng(SEED)  # reiniciado por família: permutações pareadas entre modelos
        Xp = X.copy()
        deltas = []
        for _ in range(REPETICOES):
            perm = rng.permutation(len(X))
            # embaralha as colunas da família juntas: a mesma permutação de linhas em todas elas
            Xp[:, cols] = X[np.ix_(perm, cols)]
            deltas.append(root_mean_squared_error(y, prever(Xp)) - base)
        linhas.append({
            "modelo": nome,
            "familia": familia,
            "n_colunas": int(len(cols)),
            "rmse_base": float(base),
            "delta_rmse_media": float(np.mean(deltas)),
            "delta_rmse_dp": float(np.std(deltas, ddof=1)),
            "repeticoes": REPETICOES,
            "seed": SEED,
        })
        print(f"{nome} | {familia}: dRMSE {np.mean(deltas):+.8f} +- {np.std(deltas, ddof=1):.8f}")
    return linhas

def ler_preds(caminho: Path):
    with np.load(caminho, allow_pickle=False) as d:
        faltando = [k for k in CHAVES if k not in d.files]
        if faltando:
            raise SystemExit(f"{caminho}: faltam as chaves {faltando}")
        split = str(np.asarray(d["split"]).item())
        dados = {k: np.asarray(d[k]) for k in CHAVES if k != "split"}
    if split not in SPLITS:
        raise SystemExit(f"{caminho}: split '{split}' inválido (esperado 'val' ou 'test')")
    tamanhos = {k: v.shape[0] for k, v in dados.items()}
    if len(set(tamanhos.values())) != 1:
        raise SystemExit(f"{caminho}: chaves com tamanhos diferentes {tamanhos}")
    out = {
        "y": dados["y"].astype(np.float64),
        "yhat": dados["yhat"].astype(np.float64),
        "ts": dados["ts"].astype(np.int64),
        "vol0": dados["vol0"].astype(bool),
        "rv60": dados["rv60"].astype(np.float64),
        "ret1": dados["ret1"].astype(np.float64),
    }
    if not (np.isfinite(out["y"]).all() and np.isfinite(out["yhat"]).all()):
        raise SystemExit(f"{caminho}: y ou yhat com NaN/inf")
    return out, split


def tercis_rv60(arg_cuts, caminho_f65: Path):
    # --rv60-cuts, se dado, tem prioridade; senão tercis de rv60_tr do cache de treino.
    if arg_cuts:
        partes = arg_cuts.split(",")
        if len(partes) != 2:
            raise SystemExit("--rv60-cuts espera 'a,b'")
        a, b = float(partes[0]), float(partes[1])
        origem = "--rv60-cuts"
    else:
        if not caminho_f65.exists():
            raise SystemExit(f"cache {caminho_f65} não existe; passe --rv60-cuts a,b")
        with np.load(caminho_f65) as d:
            rv_tr = np.asarray(d["rv60_tr"], dtype=np.float64)
        rv_tr = rv_tr[np.isfinite(rv_tr)]
        a, b = (float(v) for v in np.quantile(rv_tr, [1 / 3, 2 / 3]))
        origem = f"tercis de rv60_tr do treino ({rv_tr.size} linhas, {caminho_f65.name})"
    if not a <= b:
        raise SystemExit(f"limites de rv60 fora de ordem: {a}, {b}")
    return a, b, origem


def resumo(dimensao, grupos, erro):
    linhas = []
    for rotulo, mascara in grupos:
        e = erro[mascara]
        n = int(e.size)
        if n == 0:
            mae = rmse = razao = np.nan
        else:
            mae = float(np.mean(np.abs(e)))
            rmse = float(np.sqrt(np.mean(e ** 2)))
            razao = rmse / mae if mae > 0 else np.nan
        linhas.append({"dimensao": dimensao, "faixa": rotulo, "n": n,
                       "mae": mae, "rmse": rmse, "rmse_mae": razao})
    return linhas


def subgrupos(d, cuts):
    erro = d["y"] - d["yhat"]
    absy = np.abs(d["y"])
    dt = pd.to_datetime(d["ts"], unit="s", utc=True)
    a, b = cuts
    q = np.quantile(absy, [0.2, 0.4, 0.6, 0.8])
    q99 = float(np.quantile(absy, 0.99))
    quintil = np.searchsorted(q, absy, side="right")  # 0..4
    lim = [float(absy.min()), *map(float, q), float(absy.max())]
    rv = d["rv60"]
    horas = np.asarray(dt.hour) // 6
    blocos = ["00-05h", "06-11h", "12-17h", "18-23h"]

    linhas = []
    linhas += resumo("volume", [("Volume = 0", d["vol0"]),
                                ("com negócio (Volume > 0)", ~d["vol0"])], erro)
    linhas += resumo("|y| quintil", [
        (f"Q{k + 1}: |y| de {lim[k]:.3e} a {lim[k + 1]:.3e}", quintil == k) for k in range(5)], erro)
    linhas += resumo("|y| top 1%", [
        (f"top 1% (|y| >= {q99:.3e})", absy >= q99),
        (f"demais 99% (|y| < {q99:.3e})", absy < q99)], erro)
    linhas += resumo("rv60 tercil", [
        (f"T1: rv60 <= {a:.3e}", rv <= a),
        (f"T2: {a:.3e} < rv60 <= {b:.3e}", (rv > a) & (rv <= b)),
        (f"T3: rv60 > {b:.3e}", rv > b)], erro)
    linhas += resumo("ano (UTC)", [(str(ano), np.asarray(dt.year) == ano)
                                   for ano in sorted(set(np.asarray(dt.year)))], erro)
    linhas += resumo("hora UTC", [(blocos[k], horas == k) for k in range(4)], erro)
    return linhas


def piores(d):
    erro_abs = np.abs(d["y"] - d["yhat"])
    idx = np.argsort(-erro_abs, kind="stable")[:N_PIORES]
    ts_utc = pd.to_datetime(d["ts"][idx], unit="s", utc=True).strftime("%Y-%m-%d %H:%M")
    return pd.DataFrame({
        "posicao": np.arange(1, idx.size + 1),
        "ts_utc": np.asarray(ts_utc),
        "y": d["y"][idx],
        "yhat": d["yhat"][idx],
        "erro_abs": erro_abs[idx],
        "vol0": d["vol0"][idx],
        "rv60": d["rv60"][idx],
        "ret1": d["ret1"][idx],
    })


def sinal(d):
    # Extra de sinal: só y != 0. Acerto conta ŷ = 0 como erro; a matriz exclui ŷ = 0 (n_yhat_zero).
    y, yh = d["y"], d["yhat"]
    m = y != 0
    yy, yhm = y[m], yh[m]
    real_sobe = yy > 0
    acerto = float(np.mean(np.sign(yhm) == np.sign(yy)))
    tem = yhm != 0
    rs, ps = real_sobe[tem], yhm[tem] > 0
    base = float(max(real_sobe.mean(), 1 - real_sobe.mean()))
    return {
        "n_linhas": int(y.size),
        "n_y_diferente_de_zero": int(yy.size),
        "n_yhat_zero": int(np.sum(yhm == 0)),
        "acerto": acerto,
        "acerto_baseline_classe_majoritaria": base,
        "matriz": {
            "real_sobe": {"prev_sobe": int(np.sum(rs & ps)), "prev_desce": int(np.sum(rs & ~ps))},
            "real_desce": {"prev_sobe": int(np.sum(~rs & ps)), "prev_desce": int(np.sum(~rs & ~ps))},
        },
        "nota": "extra de sinal: sem backtest, custo ou P&L; yhat = 0 conta como erro no acerto",
    }

def estatisticas(y: np.ndarray) -> dict:
    a = np.abs(y)
    return {
        "n": int(len(y)),
        "media": float(y.mean()),
        "desvio": float(y.std()),
        "min": float(y.min()),
        "max": float(y.max()),
        "assimetria": float(skew(y)),
        "curtose_excesso": float(kurtosis(y)),  # Fisher: normal = 0
        "abs_quantis": {
            "p50": float(np.quantile(a, 0.50)),
            "p90": float(np.quantile(a, 0.90)),
            "p99": float(np.quantile(a, 0.99)),
            "p99_9": float(np.quantile(a, 0.999)),
        },
        "pct_zero": float(100 * np.mean(y == 0)),
    }


def correlacoes(x: np.ndarray, y: np.ndarray) -> dict:
    return {
        "spearman": float(spearmanr(x, y)[0]),
        "pearson": float(pearsonr(x, y)[0]),
    }
